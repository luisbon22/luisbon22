## Featured projects

### 🏦 [PTrinity](https://github.com/luisbon22/PTrinity)
Banking platform: customers, savings and checking accounts, deposits, withdrawals, transfers and account statements.
- **Hexagonal architecture** following **SOLID** principles, with **ACID** transactions and pessimistic locking.
- **134 tests** with 100% line coverage; the build fails if coverage drops below 85%.
- **CI/CD** with GitHub Actions, images published to GHCR, and three environments (dev, QA, production) using Git Flow.

`Java 21` `Spring Boot` `PostgreSQL` `Flyway` `React` `Docker` `GitHub Actions`

### 📦 [StockFlow](https://github.com/luisbon22/stockflow-microservices)
Order and inventory system built as **two microservices**, each with its own database.
- Communication via **REST** and **asynchronous events on RabbitMQ**, with idempotent processing and dead letter queues.
- Fault tolerance with a **circuit breaker** (Resilience4j), timeouts and retries with backoff.
- **Angular** admin dashboard and **161 tests** with over 93% coverage per module.

`Java 21` `Spring Boot` `MySQL` `PostgreSQL` `RabbitMQ` `Angular` `Docker`

### ⚽ [CanchaYa](https://github.com/luisbon22/CanchaYa)
Sports field booking app with admin and customer roles.
- **JWT** authentication with Spring Security.
- Overlapping bookings prevented at two levels: **pessimistic locking** and a PostgreSQL **exclusion constraint**.
- **React** frontend packaged with the backend in a single Docker image.

`Java 21` `Spring Boot` `Spring Security` `PostgreSQL` `React` `Docker`
