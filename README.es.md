## Proyectos destacados

### 🏦 [PTrinity](https://github.com/luisbon22/PTrinity)
Plataforma para una entidad financiera: clientes, cuentas de ahorros y corrientes, consignaciones, retiros, transferencias y estados de cuenta.
- Arquitectura **hexagonal** con principios **SOLID** y transacciones **ACID** con bloqueo pesimista.
- **134 pruebas** con 100 % de cobertura de líneas; el build falla si baja del 85 %.
- **CI/CD** con GitHub Actions, imágenes en GHCR y tres ambientes (dev, QA, producción) con Git Flow.

`Java 21` `Spring Boot` `PostgreSQL` `Flyway` `React` `Docker` `GitHub Actions`

### 📦 [StockFlow](https://github.com/luisbon22/stockflow-microservices)
Sistema de pedidos e inventario con **dos microservicios**, cada uno con su propia base de datos.
- Comunicación por **REST** y **eventos asíncronos en RabbitMQ**, con procesamiento idempotente y DLQ.
- Tolerancia a fallos con **circuit breaker** (Resilience4j), timeouts y reintentos con backoff.
- Panel de administración en **Angular** y **161 pruebas** con más del 93 % de cobertura por módulo.

`Java 21` `Spring Boot` `MySQL` `PostgreSQL` `RabbitMQ` `Angular` `Docker`

### ⚽ [CanchaYa](https://github.com/luisbon22/CanchaYa)
Aplicación de reservas de canchas deportivas con roles de administrador y cliente.
- Autenticación **JWT** con Spring Security.
- Reservas solapadas imposibles en dos capas: **bloqueo pesimista** y **restricción de exclusión** en PostgreSQL.
- Frontend en **React** empaquetado con el backend en una sola imagen Docker.

`Java 21` `Spring Boot` `Spring Security` `PostgreSQL` `React` `Docker`
